Four ways to look for anemia, running side by side.

An open collection of nail, eye, and skin based screening models pulled from Hugging Face, plus one script that downloads all four so you can compare them on your own machine.

Why bundle these together

Anemia screening research keeps circling back to the same idea: low hemoglobin shows up as visible pallor in a handful of body sites. Four independent teams built classifiers around four different sites. Nobody had put them in one place to download and compare, so this does that.

The four models

Each one ships from its own Hugging Face repo, under its own author. This project only adds the downloader and this summary.

JetX-GT/
nail-anemia-detector

Nail Anemia Detector

Reads color features from a fingernail photo (brightness, redness, pallor ratio) and classifies with an MLP. Trained on 3,406 images from 443 patients in the Ghana fingernail anemia dataset.

AUC0.75
Accuracy73%
Recall90%
Specificity46%
galihkjaya/
anemia-palor-detection

Anemia Pallor Detection

Image classifier trained to flag general pallor as an anemia indicator, without narrowing to one specific body site.

thismad/
vit-anemia-conjunctiva

ViT Anemia Conjunctiva

A Vision Transformer trained on conjunctiva (inner eyelid) images. The conjunctiva is a common site in published anemia research, since it stays visible and carries no melanin to distort the reading.

DrateHillary/
Attention_Fusion_Anemia_Model

Attention Fusion Anemia Model

Combines more than one input signal through an attention fusion architecture, instead of scoring a single image type on its own.

Get all four locally

One dependency, one script. Each model lands in its own folder next to it.

$ pip install huggingface_hub
$ python download_anemia_models.py

Limitations

None of these four models diagnose anemia. Each is a screening signal trained on one research group's dataset, and none has been validated at clinical scale.

Treat any result as a reason to get a real blood test, not as a replacement for one.
